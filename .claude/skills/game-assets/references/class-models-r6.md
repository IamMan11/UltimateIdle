# ตัวละคร R6 แบบบล็อก (stylized) — วิธีทำ + บทเรียนที่ผู้ใช้สั่งแก้มาแล้ว

ใช้คู่กับ `3d-models.md` (topology/budget) · `blender-python.md` (เขียน bpy) · ภาพ/กติกาภาพของเกมอยู่ใน style doc ของโปรเจกต์ (`docs/art-style.md`) · พิกัด/Custom Properties ตาม README ของโฟลเดอร์ asset
คอลัมน์ "helper" = ชื่อฟังก์ชันที่ควรมีใน lib สร้างโมเดลของโปรเจกต์ (เขียนครั้งเดียว ใช้ทุกตัว)

## 2. กติกาจากที่ผู้ใช้สั่งแก้ (ทำผิดซ้ำไม่ได้)

1. **ปก คอวี ซิป กระดุม กระเป๋า ช่องเปิดเสื้อกั๊ก เชือกผูกหน้า ดาว = ลายบน texture ของลำตัว (decal)** — ไม่ทำเป็นแผ่น 3D แยกวางบนผิว
2. **ของที่พันรอบตัวต้องต่อเนื่องเป็นวงเดียวทุกด้าน** (หน้า บ่า ข้าง หลัง) ไม่มีปลายขาด/โผล่/ลอย — ห้ามประกอบจากกล่องหลายท่อนชนกัน
3. **ของที่ซ้อนกัน: ชิ้นบนต้องแนบผิวของชิ้นข้างใต้** (เช่น ผ้าแดงทับเชือก+ปม → ใส่เชือก/ปมใน solids ของ Band) — **ห้ามแก้ซ้อนด้วยการยกหนี/ย้ายตำแหน่ง/ซ่อนในกัน** · ลำดับที่ผู้ใช้บอก (อะไรอยู่ใต้อะไร) ต้องตรง
4. หมวก/ฮู้ดต้องเรียบเป็นชิ้นเดียวตามผิวหัว ไม่ใช่กล่องหลายก้อน · สายแว่น/ผ้าคาดต้องแนบหมวก ไม่ยื่นเลยขอบ
5. ปมผ้า/ปมเชือกต้องดูเป็นปม (แกนปม + หูปม + ชายแยก) ไม่ใช่แผ่นสี่เหลี่ยม
6. รองเท้าไม่มีแผ่นพื้นสี่เหลี่ยมยื่นเป็นแท่ง · กางเกง/ขาเป็นแท่งตรงเรียบ
7. **แก้เฉพาะจุดที่ผู้ใช้วง** — ห้ามเปลี่ยนส่วนอื่น (เคยทำบ่าแขน/ถุงมือเรียบเกินคำสั่งแล้วโดนให้คืน)
8. เม็ด/ระเบิด/ลูกกระสุนที่เรียงบนสาย = เว้นระยะเท่ากันตามความยาวสาย ไม่กองรวม

## 3. ตรวจก่อนส่งทุกครั้ง

- render **360°: 8 มุมรอบตัว + บน + ล่าง ในท่ากางแขนออกข้าง** (หมุนแขนรอบข้อไหล่ R6 (±1, 0, 0.5) เฉพาะตอน render — ไม่ save ท่าลง .blend เพราะ export เอาท่าติดไป) + ซูมรอยต่อ (คอ บ่า ข้างตัว เอว หลัง หัว) แล้ว **ดูภาพเองให้ครบ** ก่อนบอกผู้ใช้
- นับ tri หลัง evaluate (`check`) — ร่างหลัก ≤ ~3.5k/ชิ้น · ลำตัวที่มีผ้าแนบผิวได้ถึง ~6.5k
- ส่งภาพเช็ก + บอกสั้น ๆ ว่าแก้อะไร

## 4. ทำงานกับไฟล์ที่ผู้ใช้เปิดอยู่

- ผู้ใช้เปิด .blend ใน Blender (MCP `execute_blender_code`) → เช็ก `bpy.data.filepath` + `is_dirty` ก่อน
- ก่อนเขียนทับ: เทียบ mtime ที่ stage ไว้ (`expectedMtimeMs`) + เทียบ hash vertex/modifier/transform ของทุก object กับไฟล์บนดิสก์/ใน Blender — ต่างจากที่สคริปต์สร้างเดิม = ผู้ใช้แก้มือ → ถาม
- เขียนแล้ว reload ด้วย `bpy.ops.wm.open_mainfile(filepath=..., load_ui=False)` (มุมกล้องผู้ใช้ไม่เปลี่ยน)
- build/render ใน cloud ได้ด้วย `pip install bpy` (5.2) ถ้าเครื่องผู้ใช้ไม่มี Blender CLI
